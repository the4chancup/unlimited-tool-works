Old exports and the UTW format

The managers keep making their exports in the old format (the AET format, the layout the wiki's export page describes) and keep testing them with Red. Unlimited Tool Works compiles a different layout, the UTW format, so each old export is upgraded once before you compile it. This page shows what changes and how the upgrade gets there.

In one sentence: quick_upgrade.bat reads each export in old_exports together with the official save (the base save with the managers' .ted files imported), and writes a new copy in the UTW format into exports. The old export is never changed.

What is different

The two formats hold the same models, textures and kits. What changes is where things sit, and how much the folders tell you without looking in the save.

AET format (old)UTW format (new)
A player's lookSpread over three places: his face in Faces/, his boots in Boots/, his gloves in Gloves/.One folder per player, Players/05 - Snuffy/, holding his face, hair, boots and gloves.
Who wears which bootsBoots and gloves folders are numbered (k0915, g2635). Only the save says which player wears which number.The player's own folder says it: the boots are in it, or a small link file in it points to boots several players share.
KitsConfigs in Kit Configs/, textures in Kit Textures/, colours in the Team Note.One folder per kit, Kits/p1/ to Kits/p9/ and Kits/g1/, each holding its texture, its settings and its colours together.
Skin colour, build, strip styleOnly in the save.Copied from the official save into each player's settings.toml, so the export carries them too. The compile's patch writes them into the save, so the two always agree.
Team colours and notesIn the Team Note text file.In colors.txt and notes.txt.
Boots and gloves IDsThe numbers in the folder names.The same numbers, kept in legacy_ids.toml. The official DLC keeps the IDs each manager chose, so the test CPKs they build with Red still match the official save.
The export's nameco Springco Full Spring (Midcup instead of Full when the old name said "midcup" or "additions"). A Full export is the team's whole set; a Midcup one only adds to it.

Why the upgrade needs the official save

An old boots folder is only a number and a name. Nothing in the export says who wears it: the save does. The upgrade looks every number up in the official save and sorts the boots and gloves accordingly.

What the upgrade window tells you

  • Each export is upgraded whole or not at all. When something stops an export (a team the save does not hold, a file that cannot be read), nothing is written for it, and the window says why above the line that counts the exports upgraded. Fix the cause and run quick_upgrade.bat again.
  • Files the game never used are left out. Red never put the Other folder, backup copies or stray files into the game, so the upgrade leaves them out too and lists each one as a warning; the export still upgrades.
  • An export is upgraded once. If its folder is already in exports, the window lists it as not upgraded ("the output folder already exists") and leaves the folder as it is. Move upgraded exports out of old_exports once they are done.
  • The referee export takes no save. Its name starts with refs, and the "Upgrading old exports" section of README.txt has the one command that upgrades it.
