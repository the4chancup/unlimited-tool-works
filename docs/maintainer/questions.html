    The game's own descriptions as tooltips: bundled, or read from the install?

    From: chat 2026-11-20, the lookup run (4cc-studio-temp/lng_re/out/findings.md)

    PES 2014, 2017 and 2021 (the three checked) keep their on-screen text in one file of a language archive, eng/string/all.str, in one format: zlib-compressed sections of numbered strings, with no encryption. It holds the descriptions of skill cards, COM playing styles, Game Plan strategies and sliders, and the suite already reads the archives. A name and its description do not always share a number, so each kind of item needs a small table that maps it to its description.

    Should the tooltips carry text bundled in the suite, or read from the member's own install?
