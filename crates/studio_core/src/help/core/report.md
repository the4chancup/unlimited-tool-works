When the program does something wrong, **Report a problem**, in the sidebar
just above **Help** (the `⚠` when the sidebar is folded), saves a file to post
with your report, so whoever looks into it can repeat what you did. Nothing is
sent: you post the file yourself, wherever you usually report problems.

The file holds:

- a line for each tool you used since the window opened, with how many steps
  you took in it, the first file it opened and the last one it wrote;
- the files each tool opened, as they were before any change, the files it
  wrote, and its state now (in the Save editor, the open save with your edits);
- the program's log, its version, your settings and the PES installs found.

In the box, write what you did, what you expected and what you got, and
anything done outside the program, in the game or in another tool. The words
stay there until the window closes, so you can close the dialog and finish
them later.

**Save…** asks where to put the file, which is named by the date and time
(`utw-report-2026-11-15-1030.zip`). The file holds your whole save; in the
paths it records, your username is written `~`.
